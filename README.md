## 📌 О проекте

Небольшой многоголосый цифровой синтезатор, который превращает нажатия кнопок
в звук. Проект находится в активной разработке: цифровая часть уже генерирует
звук, а для аппаратной версии разрабатывается отдельная печатная плата
с клавиатурой и аналоговым усилителем на советских транзисторах
**КТ315** и **КТ361**.

---

## 🎶 Что умеет

- **14 независимых голосов** — по одному на каждую клавишу.
- **Полная полифония** — можно зажимать несколько кнопок и получать аккорды.
- У каждой ноты — **собственный фазовый аккумулятор** и **собственная огибающая амплитуды**.
- Никаких таблиц синусоид, ROM с семплами и wav-файлов.

## ⚙️ Генерация звука

Каждая нота реализована отдельным экземпляром модуля **`voice`**.

Голос содержит:

| Компонент              | Назначение                          |
|------------------------|-------------------------------------|
| Фазовый аккумулятор    | Накопление текущей фазы сигнала     |
| Приращение фазы `note_step` | Определяет частоту ноты        |
| 8-битная огибающая     | Управление амплитудой (Attack/Release) |

Фаза увеличивается на каждом такте:

```verilog
phase <= phase + note_step;
