# FPGA SYNTH

Небольшой многоголосый цифровой синтезатор на FPGA, который превращает нажатия кнопок в звук без MIDI, операционной системы, DSP-библиотек и прочей цивилизации.

Проект находится в разработке. Цифровая часть уже умеет генерировать звук, а для аппаратной версии разрабатывается отдельная печатная плата с клавиатурой и аналоговым усилителем на советских транзисторах КТ315 и КТ361.

## Что умеет?

Синтезатор имеет 14 независимых голосов.

Каждая кнопка соответствует одной ноте:

Кнопка	Нота
key[0]	C4
key[1]	D4
key[2]	E4
key[3]	F4
key[4]	G4
key[5]	A4
key[6]	B4
key[7]	C5
key[8]	D5
key[9]	E5
key[10]	F5
key[11]	G5
key[12]	A5
key[13]	B5

Можно одновременно нажимать несколько клавиш и получать аккорды.

Каждая нота имеет собственный фазовый аккумулятор и собственную огибающую амплитуды.

## Аппаратная часть

Основой является FPGA Tang nano 20k с тактовой частотой 27 МГц.

Выход:
audio — цифровой PWM-аудиосигнал.

В текущей реализации audio выводится непосредственно с FPGA на динамик через резистор 330 Ом.

Для законченной аппаратной версии разрабатывается отдельная печатная плата.
На ней будут размещены:
- 14 физических кнопок
- УНЧ на самых прекрасных транзисторах (КТ315 и КТ361)

##Генерация звука

Каждая нота реализована отдельным экземпляром модуля voice.

Голос содержит:

фазовый аккумулятор;
приращение фазы note_step;
8-битную огибающую амплитуды.

Фаза увеличивается на каждом такте:

phase <= phase + note_step;
Старший бит фазового аккумулятора используется для формирования прямоугольного сигнала.
Таким образом, отдельная таблица синусоид не нужна.
Никаких ROM с семплами.
Никаких wav-файлов.
FPGA просто чОтка считает фазу и периодически меняет знак сигнала.

Получается цифровая прямоугольная волна.
